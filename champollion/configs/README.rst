#############
config README
#############

This folders contains the configuration yaml files to pass relevant keywords to hydra.

In each folder, there are one or several yaml files that contain keywords specific to the topic of the folder.
There is a main file ``config.yaml`` that is used to specify for each folder which yaml file should be used.


augmentations
-------------
Parameters related to SSL data augmentations.

backbone
--------
Parameters related to the SSL backbone.

dataset
-------
Parameters related to the dataset used for training. Each file contains the path to the numpy arrays,
the info csv and a few more info, like the input shape.

dataset_localization
--------------------
Yaml files that define the ``dataset_folder`` variable used by dataset configs with interpolated paths
(e.g. ``${dataset_folder}/TESTXX/crops/...``). The ``local.yaml`` file is typically generated by
``generate_champollion_config.py`` (when using ``champollion_pipeline``) and points to the actual data directory on the current machine.

hydra
-----
Mandatory yaml for hydra to function properly. It contains notably the path where the models are saved.

mode
----
Files that contains the loss choice and related parameters.

model
-----
A single file that contains parameters related to the SSL model as a whole, such as drop rate, temperature or if 
you want to use pretraining. It also contains parameters about the "converter" (a layer that fuse latent spaces when 
multiple encoder are used).

platform
--------
Parameters related to the environment set for training (choice between cpu and gpu, number of workers).

projection_head
---------------
Parameters related to the projection head, such as its layers' activation and shape.

trainer
-------
Parameters related to the training process, such as learning rate, proportions of train/val, max number of epochs, etc.
